## 0. 技术与数据约束（影响功能，不影响视觉）

- **实现位置**：本仓库 `frontend-gpt/` 为独立 React 工程（`npm ci && npm run dev`，127.0.0.1:5178），另有外部前端工程。后端 API 单独运行（`scripts/serve.py`，127.0.0.1:8666），接入方式见 §5.0；本地生产预览为 `npm run build && npm run preview`（4178，含 API 代理）。
- **离线单机**：后端不依赖任何外部资源；前端工程如需联网资源（CDN/网络字体）自行权衡，与后端无关
- **数据源**：全部走本地后端 API（见 §5），前端不直连数据源
- **数据语义**（功能性约定，具体呈现由设计决定）：
  - 涨/跌是核心语义，A股惯例**红涨绿跌**，涨跌标识需全局一致
  - 盯盘"灯"是独立状态指示，**视觉上必须能与涨跌区分**（不能用同一对颜色）
- **切 tab 不丢状态**：三个页面常驻挂载（display 切换），用户来回切换时已选标的/分页/滚动位置不重置——这是既定操作逻辑，改版须保留

## 1. 页面总览

单页应用，顶部导航三个 tab：

| Tab | 页面 | 一句话功能 |
|---|---|---|
| 行情 | KlineBrowser | 浏览本地 K 线：列表选股 → 图表 + 明细，可回源补最新 |
| 因子 | FactorBrowser | 浏览因子库与已落盘因子值，四级下钻 |
| 盯盘 | MonitorBoard | 管理日内盯盘任务（Python 脚本），看信号灯与信号历史 |

（页面/组件命名为功能代号，具体代码组织由前端工程自定。）

## 2. 行情页（KlineBrowser）

**功能**：浏览本地缓存的 K 线数据，并以图表 + 明细表查看；可手动/自动回源补最新数据。

**布局逻辑**：左侧标的列表（可折叠）+ 右侧详情区（选中标的后出现）。

**左侧标的列表**：
- **一个标的一行**（不是 标的×周期 平铺）：`/api/coverage` 返回的是 标的×周期 明细，前端按 symbol 归组后展示，行内可见该标的已存哪些周期
- `搜索框`：按代码/名称过滤，回车触发
- `周期下拉`：按 K 线周期过滤（1d / 1m / 5m / 15m / 30m / 60m）——筛选"存有该周期数据"的标的
- `折叠按钮`：选中标的后出现，把列表收成窄条以腾出图表空间；窄条点击重新展开
- 列表列：代码 / 名称 / 数据截止时间；**点击行 = 选中该标的**，载入右侧详情
- 分页：50 条/页
- 数据来源：`/api/coverage`（本地已存数据的覆盖索引，不是全市场列表）

**右侧详情区**：
- **周期切换**：详情区内可切换该标的已存周期（1m / 5m / 15m / 30m / 60m / 1d 等，以 coverage 里该标的存在数据的周期为准），切换后图表与明细表整体重载，**不返回列表重选**
- **报价摘要**：展示最新一根 bar——代码、名称、周期、收盘价、相对开盘的涨跌幅（带涨/跌方向）、开/高/低/量/额
- `日期范围选择器`：限定区间后重新查询图表和明细；清空恢复全量
- `已存 X ~ Y` 提示：本地缓存的实际覆盖区间
- **`取最新` 按钮**：回源 TickFlow 拉取最新行情（含当日盘中 bar），成功后覆盖提示推进到当前；失败时弹警告并退回缓存数据，不阻断查看
- **选中即刷新**：点击左侧列表行时自动执行一次"取最新"（用户看哪只就补哪只）
- **K 线图**（ECharts）：蜡烛图 + MA5/MA10/MA20 三条均线 + 副图成交量 + 滚轮/滑块缩放；分钟周期的时间轴精确到分钟；无数据时显示空态
- **明细表**：时间 / 开 / 高 / 低 / 收（带涨跌着色）/ 量 / 额；服务端分页，每页 20/50/100/200 可选

## 3. 因子页（FactorBrowser）

**功能**：浏览因子注册表 + 已计算落盘的因子值。**四级下钻**：因子 → 已存目录（参数指纹）→ 组合明细（标的×周期）→ 因子值。

- `搜索框`：按因子名/说明过滤
- **因子表**：名称 / 默认参数 / 版本 / 类别 / 说明 / 已存目录数；点击行下钻到目录
- **目录表**：参数指纹 / 参数 / 版本 / 复权方式 / 组合数 / 总行数；点击行下钻
- **组合明细表**：标的 / 周期 / 行数；点击行下钻
- **因子值表**：时间 / 值；服务端分页（20/50/100/200）
- 每级有节标题标明当前下钻路径（如「已存数据目录 · ma」「因子值 · ma {"n":20} · 600869.SH 1d」）

## 4. 盯盘页（MonitorBoard）

**功能**：管理日内盯盘任务。任务 = 一段 Python 脚本（`check(ctx)`，存在数据库里、页面上可查看可编辑）+ 轮询间隔 + 开关；盯盘守护进程在交易时段按间隔执行脚本，条件成立/失效时点亮/熄灭**信号灯**并推送 Bark 通知。**一个任务一盏灯**：灯亮只代表"指标生效"，生效意味着买还是卖由任务含义决定（写在任务名称/说明里），系统不预设买卖方向。

**状态带**（页面顶部）：任务总数 / 启用中 / 亮灯数 / 出错任务数 / 最近运行时间（相对时间）；右侧为 `自动刷新 10s` 开关（默认开，页面不可见时暂停轮询）、`刷新`、`新建任务`。

**任务表**列与控件：
- 任务（名称 + 说明副行，说明悬浮可看全文）/ 标的
- **信号灯**：亮 = 条件当前成立（实心琥珀灯），灭 = 不成立（空心环）；**只在"灭→亮"或"亮→灭"翻转的瞬间推送一次通知**，灯本身常亮常显（用户在页面上随时能看到条件是否成立）
- `启用开关`：即点即生效，控制守护进程是否轮询该任务
- 轮询(秒) / 轮询次数 / 信号数 / 错误数（>0 红色高亮）/ 最近运行（相对时间，悬浮见绝对时间）/ 最近错误：运行状态自检
- **`详情` 按钮**：打开抽屉查看并编辑任务
- **`删除` 按钮**：需二次确认（Popconfirm）
- 点击任务行 = 选中，下方信号历史过滤为该任务；**再点一次已选中行 = 取消选中**，信号历史回到全部

**信号历史表**：时间 / 事件 chip（灯亮、灯灭）/ 触发时价格 / 信息；50 条/页。有过滤任务时表头显示任务名与 `查看全部` 快捷清除。

**任务抽屉**（新建/详情共用）：名称、标的（如 600869.SH）、轮询间隔（秒，最小 60）、信号通知开关、说明（可选）、盯盘脚本（Python，等宽多行编辑）；`保存` 时名称/标的/脚本任一为空则拦截提示，并把空缺字段标红。

**脚本怎么写**：见 `.claude/skills/monitor-expert/SKILL.md`（盯盘专家 skill，含 ctx API 与示例）。

## 5. 后端 API 详细说明

前端唯一数据来源。

### 5.0 接入方式（在其他前端工程中对接）

- **后端地址**：`http://127.0.0.1:8666`（`scripts/serve.py` 启动），接口统一前缀 `/api`，如 `http://127.0.0.1:8666/api/klines?...`
- **无鉴权、无 cookie**，纯 JSON 请求/响应，无需任何 header
- 仅监听 `127.0.0.1`，只能本机访问
- **后端未开 CORS**：浏览器从其他源（如 `localhost:5173`）直接 `fetch("http://127.0.0.1:8666/api/...")` 会被跨域拦截。**正确做法是让 dev server 代理，前端代码里始终请求相对路径 `/api/...`**：

```ts
// vite.config.ts（vite 工程）
export default defineConfig({
  server: {
    proxy: { "/api": "http://127.0.0.1:8666" },
  },
});
```

```js
// webpack devServer / CRA（webpack 系工程）
devServer: {
  proxy: { "/api": "http://127.0.0.1:8666" },
}
```

这样浏览器看到的是同源请求，代理在 Node 侧转发，没有 CORS 问题。

**通用约定**：
- 所有时间戳字段均为 **Unix 毫秒**（int）
- 分页参数：所有分页端点收 `page`（≥1，默认 1）与 `size`（1~2000，越界会被钳制），响应回显 `total / page / size`
- 列表响应包一层：`{ "total": n, "page": p, "size": s, "items": [...] }`；K 线/因子值用 `rows`（数组的数组，紧凑格式）
- 错误：FastAPI 标准 `{ "detail": "错误信息" }`，HTTP 状态码见各端点

### 5.1 `GET /api/periods` — 周期列表

无参数。

返回：
```json
{ "items": ["1m","5m","10m","15m","30m","60m","1d","1w","1M","1Q","1Y"], "total": 11, "page": 1, "size": 11 }
```

### 5.2 `GET /api/coverage` — 标的覆盖索引

本地已存 K 线的覆盖索引（**不是全市场列表**，只含本地有数据的 标的×周期），LEFT JOIN instruments 带出名简称。

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `q` | string | "" | 模糊过滤，同时匹配 symbol / code / name（LIKE %q%） |
| `period` | string | "" | 周期精确过滤（如 `1d`），空 = 全部 |
| `page` / `size` | int | 1 / 50 | 分页 |

返回 `items: CoverageRow[]`，按 symbol、period 升序：
```json
{
  "symbol": "600869.SH",   // TickFlow 完整代码
  "code": "600869",        // 6 位代码（可能为 null）
  "name": "ST众泰",        // 名称（可能为 null）
  "period": "1d",
  "start_ms": 1483200000000,  // 本地缓存最早一根 bar 时间
  "end_ms": 1783008000000,    // 最晚一根
  "updated_at": 1783065600.0  // 该覆盖记录最近写入时间（秒，float）
}
```

### 5.3 `GET /api/klines` — K 线查询

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `symbol` | string | **必填** | 如 `600869.SH` |
| `period` | string | `1d` | 须在 periods 列表内，否则 404 `unknown period` |
| `start_ms` / `end_ms` | int | 见说明 | 查询区间（毫秒）；**省略任一**则用该标的本地覆盖区间兜底；本地无覆盖时返回空 rows |
| `page` / `size` | int | 1 / 50 | 分页 |
| `refresh` | bool | false | 传 `refresh=1` 回源 TickFlow 补最新（见下） |

返回：
```json
{
  "symbol": "600869.SH",
  "period": "1d",
  "total": 1560,          // 区间内总根数
  "page": 1, "size": 50,
  "refreshed": false,     // 本次是否成功回源
  "refresh_error": null,  // 回源失败时的错误字符串（数据仍为缓存）；成功或无回源请求时不含此键/为 null
  "rows": [
    [1783008000000, 3.21, 3.25, 3.18, 3.22, 12345678.0, 39876543.0]
    // [timestamp(ms), open, high, low, close, volume, amount]，按 timestamp 升序
  ]
}
```

**`refresh=1` 语义**（前端「取最新」/选中即刷新用）：
- 懒构造 DataCenter（需 `TICKFLOW_API_KEY`），对缺失段自动回填落盘；**当日盘中 bar 走 intraday 缓存直接出现在 rows 里，但不落盘**
- 价格口径为 `adjust="none"`（原始价），与缓存路径一致，不会混口径
- 成功：`refreshed: true`，rows 直接来自回源结果（含当日）
- 失败（无 key/网络异常等）：**不报错给前端**，退回缓存数据，`refreshed: false` + `refresh_error: "..."`，由前端弹警告

### 5.4 `GET /api/factors` — 因子注册表

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `q` | string | "" | 模糊过滤因子名 / 说明（doc） |
| `page` / `size` | int | 1 / 50 | 分页（后端内存过滤后切片） |

返回 `items: FactorRow[]`，按 name 排序：
```json
{
  "name": "ma",
  "category": "trend",            // 类别
  "period": "1d",                 // 因子声明的适用周期
  "version": 1,
  "default_params": { "n": 20 },  // 默认参数
  "doc": "说明/同花顺条件句（全文，可能很长）",
  "stored_dir_count": 3           // 已落盘的参数目录数（下钻入口）
}
```

### 5.5 `GET /api/factor-dirs` — 已存因子目录

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `q` | string | "" | 模糊过滤 name / params（params 转 JSON 后匹配） |
| `page` / `size` | int | 1 / 50 | 分页 |

返回 `items: FactorDir[]`，按 (name, params JSON) 排序：
```json
{
  "fingerprint": "ma-9f3c2a...",  // 参数指纹，查因子值的钥匙
  "name": "ma",
  "params": { "n": 20 },
  "version": 1,
  "adjust": "forward",            // 计算时用的复权方式
  "period": "1d",
  "category": "trend",
  "doc": "...",
  "cells": [ { "symbol": "600869.SH", "period": "1d", "rows": 1560 } ],  // 组合明细（标的×周期×行数）
  "total_rows": 4680
}
```

### 5.6 `GET /api/factor-values` — 因子值

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `fingerprint` | string | **必填** | factor-dirs 返回的指纹 |
| `symbol` | string | **必填** | |
| `period` | string | **必填** | |
| `page` / `size` | int | 1 / 50 | 分页 |

无数据时 **404** `no stored factor data: ...`。返回：
```json
{
  "fingerprint": "...", "symbol": "600869.SH", "period": "1d",
  "total": 1560, "page": 1, "size": 50,
  "rows": [ [1783008000000, 3.2158] ]  // [ts(ms), value]；value 可为 null（NaN 归一化为 null）
}
```

### 5.7 盯盘 `/api/monitor/*`

**任务对象 MonitorTask**（GET/PUT 响应与创建入参都围绕它）：
```json
{
  "id": 1, "name": "众泰低位", "symbol": "600869.SH",
  "script": "def check(ctx): ...",   // 完整 Python 源码
  "interval_sec": 60,                // 轮询间隔秒
  "enabled": 1,                      // 0/1：守护进程是否轮询
  "notify": 1,                       // 0/1：边沿翻转是否推 Bark
  "lamp_on": 0,                      // 信号灯当前状态 0/1（单灯：条件成立=亮）
  "poll_count": 12, "signal_count": 2, "error_count": 0,
  "last_error": null,                // 最近一次错误字符串
  "last_run_at": 1783065600000,      // ms，可 null
  "created_at": 1783000000000,       // ms
  "description": "说明文字"
}
```

| 端点 | 入参 | 返回 | 错误 |
|---|---|---|---|
| `GET /api/monitor/tasks` | 无 | `{ "items": MonitorTask[] }` | — |
| `POST /api/monitor/tasks` | JSON body：`name` / `symbol` / `script` 必填；`interval_sec`(=60) / `notify`(=1) / `description`(="") 可选 | `{ "id": 1 }` | script 语法无效或缺 `check` → **400** `script 无效: ...` |
| `PUT /api/monitor/tasks/{id}` | JSON body：六字段任意子集（null 表示不改）；带 script 时同样先校验 | `{ "ok": true }` | id 不存在 → **404**；script 无效 → **400** |
| `POST /api/monitor/tasks/{id}/toggle` | 无 body；翻转 enabled | `{ "enabled": 0或1 }` | id 不存在 → **404** |
| `DELETE /api/monitor/tasks/{id}` | 无 | `{ "ok": true }` | id 不存在 → **404** |
| `GET /api/monitor/signals` | query：`task_id`(可选，过滤单任务) / `limit`(默认 200) | `{ "items": MonitorSignal[] }` | — |

**信号对象 MonitorSignal**（**按 ts DESC, id DESC —— 第 0 条即最新**，前端最新行高亮依赖此）：
```json
{
  "id": 9, "task_id": 1, "ts": 1783065600000,
  "kind": "on",           // 枚举：on 灯亮 / off 灯灭（只在边沿翻转瞬间产生一条）；
                          // 2026-09-06 前的历史数据可能含旧值 buy_on/buy_off/sell_on/sell_off，前端按原文兜底显示
  "price": 3.22,        // 触发时价格，取价失败为 null
  "message": "脚本返回的 msg，可空串"
}
```

## 6. 交互约定（功能层面，改版须保留）

- 表格行点击 = 选中/下钻，选中行有明确高亮
- 危险操作（删除盯盘任务）必须二次确认
- 回源失败不阻断查看：永远有缓存数据兜底，错误以提示呈现
- 表单必填项（盯盘任务的名称/标的/脚本）在保存前校验并明确提示
- 所有列表空数据时有空态提示

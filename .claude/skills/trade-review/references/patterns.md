# 复盘指标解读与改进建议库

> 这是 Claude 写复盘报告时的解读参考，不是硬性规则。所有指标来自 `scripts/analyze_trades.py` 的 `analysis.json`，数据为原始价日线（adjust="none"），指标只用当日及之前数据、无前视；`forward` 是卖出后的真实后续表现（复盘时才可知）。

## 进场时机指标（买入单）

| 指标 | 含义 | 怎么读 |
|------|------|--------|
| `pos_in_range` | 成交价在当日振幅中的位置 (0~1) | 买 >0.7 ≈ 追高到当日高位；<0.35 ≈ 买在低位区。**平均** >0.6 是系统性追高的信号 |
| `mom_5d_pct` / `mom_20d_pct` | 5/20 日动量 | 买前已大涨（mom_5d >8% 或连涨）再买 = 接盘风险；强势股回调 mom 刚转正是另一回事，看位置 |
| `rsi14` | 相对强弱 | 买时 >70 通常过热；50~60 健康；<40 偏弱 |
| `trend` | up/down/sideways（价格 vs MA5/20） | **逆势 = 价格在 MA20 下方且 MA5<MA20**，这是"接飞刀"，胜率最低的模式之一 |
| `price_vs_ma20_pct` | 距 20 日线 | 离 MA20 太远（>10%）买 → 均值回归回踩风险 |
| `dist_20d_high_pct` | 距 20 日高点 | 接近 0 = 买在阶段高点；深负值 = 深跌后买 |
| `vol_ratio` | 当日量 / 前 20 日均量 | 放量（>1.5）追涨要警惕是情绪高点 |
| `open_gap_pct` / `day_change_pct` | 跳空/当日涨跌 | 在放量大涨日追买 = 典型追高 |
| `close_vs_fill_pct` | 收盘 vs 你的成交价 | 买入后收盘 < 成交价说明当天就站不住 |

**买得好的特征**：顺趋势（trend=up）、买在低位区（pos_in_range ≤0.35）、回调到均线附近（price_vs_ma20 ≈ -2%~0）、量能温和。

**买得差的模式（改进重点）**：
1. **追高**：pos_in_range ≥0.7 或 mom_5d ≥8% 或 mom_20d ≥25% 或 price_vs_ma20 ≥15% 或 RSI ≥70 → 情绪高点接盘，回调即套。**别只看 5 日**：一只票月内已大涨（mom_20d 高）或已远超 MA20 再买，即使 RSI 不高也是追高。
2. **逆势接飞刀**：trend=down 还买 → 趋势没止跌前买入，浮亏长。等 MA20 走平/站回再说。
3. **离均线太远追买**：price_vs_ma20 >10% → 等回踩。
4. **同一标的连续加仓摊平**：亏了继续买 → 从行为统计看多笔同标的买入间隔与价格。

## 出场时机指标（卖出单）

| 指标 | 含义 | 怎么读 |
|------|------|--------|
| `fwd_1d/5d/10d_pct` | 卖出后 N 日涨幅 | **>3%（尤其 5 日）且经常出现 = 系统性卖飞/止盈过早**。可对照：赢单卖飞 vs 亏单扛着不卖（这是最常见的盈亏不对称） |
| `pos_in_range`（卖） | 卖出在当日位置 | <0.3 且当天在跌 = 恐慌低位割肉；≥0.65 = 卖得不错 |
| `day_change_pct`（卖） | 卖出日涨跌 | 大跌日割肉（≤-3%）且当天低位卖 = 情绪化止损 |
| `trend`（卖） | 卖出时趋势 | trend=up 时卖 → 可能卖飞；trend=down 时卖 → 顺势离场更合理 |

**卖得差的模式**：
1. **卖飞/止盈过早**：赢单在上升趋势中卖出，forward 继续涨。对策：分批止盈/移动止损，趋势没破先持有。
2. **低位恐慌割肉**：在大跌日、当日低位、趋势已破位才止损 → 止损太晚，本该更早止损，且不要在最恐慌点卖。
3. **扛单到深亏**：持仓 ≥15 天、亏损 ≥-12% 才离场 → 没有预设止损，靠"回本"心理。应在买入前定好止损位。

## 持仓行为

- **平均持仓天数**：<3 天 = 快进快出（高频，佣金磨损大，胜率不高的就是给券商打工）；>20 天普遍 = 变相价值投资，但若买入是追高的，就会扛单。
- **同标的多次买卖**：看是否一涨就卖、一跌就补（摊平），用 round_trips 的多笔同一标的佐证。

## 亏损归因（脚本已按优先级分类）

| 类别 | 判定依据 | 改进方向 |
|------|---------|---------|
| 追高买入 | pos_in_range≥0.7 或 mom_5d≥8% 或 RSI≥70 | 等回调/回踩均线再买；强势股用"突破后回踩不破"确认而非追当日高点 |
| 逆势买入 | 价格<MA20 且 MA5<MA20 | 只在趋势转上后买；下跌趋势中空仓或只看不做 |
| 止损过晚/扛单 | 持仓≥15 天且亏损≥12% | 每笔买前定止损（如 -8% 或跌破关键均线），到了就走 |
| 频繁交易磨损 | 持仓≤3 天 | 减少交易频率，提高每笔质量；算一笔账：佣金+印花税对累计收益的侵蚀 |

## 行为画像表述技巧（反推交易模式）

用户说"没有固定模式"，所以**从数据反推他的真实模式**。典型画像话术：

- "你的实际模式接近『趋势追涨 + 短线持有』：买入平均 pos_in_range 0.7，追高 4/6 笔，但持仓平均仅 5 天就卖出。"
- "你买入的共性不是某个指标，而是『刚大涨就买』（mom_5d 平均 +9%）和『跌了就摊平』（3 次同标的补仓均价逐笔更低）。"
- "你的卖出更像『情绪反应』而非规则：赢单卖飞 60%，亏单却平均扛 18 天。"

画像要给"如果按某类模式重新做，止损点应该设在哪"这类具体建议，而不是泛泛说"要止损"。

## 注意事项

- 盈亏为**价差口径**（不含佣金/印花税）。高频交易者报告中要提醒费用侵蚀。
- 别把 forward 收益当"当时就该知道"——那是复盘视角，用于总结规律，不是指责。
- 数据不足（forward 为 null / 标的无数据）的地方明确标注，别硬编。
